# Christmas 2026

Family dashboard for Christmas 2026: the boys' wishlist, who is bringing what, the plan and Secret Santa.

- `index.html` is the whole site, hosted on GitHub Pages.
- `apps-script.gs` is the backend. It lives in the "Christmas 2026 presents" Google Sheet and reads and writes both Christmas Sheets.
- With `API_URL` empty the site runs in preview mode with sample data and nothing is saved.
